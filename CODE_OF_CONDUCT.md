# Code of conduct

OpenOmicsBench is a place to discuss data, methods and software. Specific criticism is welcome. Personal attacks are not.

Be civil in issues, pull requests and reviews. Explain disagreements with evidence where possible, and give others room to correct mistakes. Do not harass people, use discriminatory language, make threats, disrupt discussions deliberately or share someone's private information without consent.

For a public moderation concern, open an issue and link to the relevant discussion. Leave private details out of the issue. For conduct in a GitHub comment that needs a private report, use GitHub's **Report content** option on that comment. GitHub handles those reports under its own policies. The maintainer may also hide comments, lock discussions or close contributions that break these expectations.
