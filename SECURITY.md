# Security policy

## Supported versions

The latest published OpenOmicsBench release is the supported version. Older releases remain archived but are not routinely patched.

## Report a vulnerability

Use [GitHub's private vulnerability report](https://github.com/vxxqv/openomicsbench/security/advisories/new). Include the affected version, a minimal way to reproduce the problem and its likely impact. Please allow time for a private assessment before publishing details.

Do not put an unpatched vulnerability in a public issue. For ordinary bugs or dataset corrections, use the repository's issue templates.
