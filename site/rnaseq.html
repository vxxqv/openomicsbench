Bulk RNA-seq · count matrices · differential expression

Check your RNA-seq inputs before you compare results.

OpenOmicsBench provides small, traceable count matrices from published studies. Export aligned counts, sample metadata and a declared contrast, inspect sample-level count quality, then assess the results your pipeline produces.

01 / Walkthrough

A paired study you can inspect.

rnaseq-005 is a published prostate tumour versus adjacent non-tumour comparison. Its compact pack has 8,000 genes and 28 samples. The sample sheet records the paired blocking factor, and the contrast declares tumour minus adjacent tissue. Adjacent tissue is not a healthy control.

python -m pip install openomicsbench
omicsbench rnaseq pack rnaseq-example --id rnaseq-005
omicsbench rnaseq qc rnaseq-example/rnaseq-005/counts.tsv --samples rnaseq-example/rnaseq-005/samples.tsv --contrasts rnaseq-example/rnaseq-005/contrasts.tsv --id rnaseq-005

The report lists library size, detected genes, zero fraction and the largest-gene fraction for each sample. It checks sample IDs and design rank. A zero-count library fails. Counts alone cannot establish read quality or biological validity.

02 / Result checks

Inspect your differential-expression calls.

After DESeq2, edgeR or limma has produced a native CSV or TSV table, run:

omicsbench rnaseq assess-de rnaseq-005 results.csv --alpha 0.05
omicsbench rnaseq score-effects rnaseq-005 results.csv

The first command reports adjusted-p-value calls, missing values, effect-direction agreement and gene-effect rank agreement with the archived DESeq2 reference. The second applies the existing effect-scoring thresholds. Both commands expect effects for the declared target-minus-reference contrast; use --reverse-sign only if your result uses the opposite direction.

If you have an independently established table of gene_id,is_de labels, add --truth labels.tsv to assess-de for precision, recall and F1 within that labelled gene set. The command requires every labelled gene to have an adjusted p-value. Agreement with one reference analysis is not an independent truth set or an estimate of false-discovery calibration.
