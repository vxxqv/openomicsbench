# Changes

## 0.1.0.dev0

The first development snapshot provides local discovery, typed manifests, hash-checked tier retrieval, cache verification and count-based diagnostics. File inventories are explicit, and validation rejects changed counts, mismatched sample order and confounded condition and batch designs.

A generated fixture now exercises the full local path from construction to retrieval and validation. A separate Pasilla workflow retrieves a pinned source table and records the outcome of six feature-reduction sizes. Source counts remain outside the distributable repository while rights and reference review continue.

Twelve GEO records have been screened. One is excluded because it is single-cell, and a mixed-assay superseries requires subseries resolution. These records are candidates, not twelve completed datasets.

The Pasilla DESeq2 baseline and the Snakemake fixture workflow now run in the recorded isolated environment. The v1.0 release remains open because no version DOI has been minted and no biological pocket has been cleared for redistribution.
