**Status, 27 November 2026:** six CellBench cases passed source, reference-identifier, transformation and package validation and are included in the v15 candidate. Other sources below remain candidates and are not scored.

The seven pinned CellBench source pairs passed a structural audit in [v15-cellbench-source-audit.json](v15-cellbench-source-audit.json). The audit checked gzip files from upstream commit `7d00ffb0bd043467f365a9358d7312f294f13c9f`, matching count/metadata cell IDs, unique feature IDs, nonnegative integer counts, and the presence of demuxlet labels. The matrices contain 902, 274, 225, 3,918, 297, 307 and 305 cells in the order listed above.

The [feature-reference audit](v15-cellbench-reference-audit.json) compares source identifiers with the downloaded [Ensembl 88 GRCh38 GTF](https://ftp.ensembl.org/pub/release-88/gtf/homo_sapiens/Homo_sapiens.GRCh38.88.gtf.gz) and [GENCODE 26](https://www.gencodegenes.org/human/release_26.html). The three-line matrices match all Ensembl gene IDs after excluding ERCC controls. The five-line CEL-seq2 plates have 18, 11 and 8 IDs absent from Ensembl 88, respectively; any compact derived cases must exclude and record them. The five-line 10x matrix uses mostly gene symbols, with 773 names absent from the Ensembl 88 gene-name set, so it remains a candidate. Identifier overlap alone does not prove which GTF the original aligner used.

The [upstream repository](https://github.com/LuyiTian/sc_mixology) declares an MIT license at the pinned commit. The individual GEO records provide more precise reference provenance: [three-line 10x](https://www.ncbi.nlm.nih.gov/geo/query/acc.cgi?acc=GSM3022245) and [five-line 10x](https://www.ncbi.nlm.nih.gov/geo/query/acc.cgi?acc=GSM3618014) name GRCh38 patch 10; [three-line CEL-seq2](https://www.ncbi.nlm.nih.gov/geo/query/acc.cgi?acc=GSM3336845), [Drop-seq](https://www.ncbi.nlm.nih.gov/geo/query/acc.cgi?acc=GSM3336849) and [the three five-line CEL-seq2 plates](https://www.ncbi.nlm.nih.gov/geo/query/acc.cgi?acc=GSM3618022) name Ensembl GRCh38 release 88. The six derived cases preserve selected source counts and all selected cell labels; excluded unmatched feature IDs are recorded per case. Each case passes package validation. The cases are from one study, including three technical plates, and must not be described as independent cohorts.

The release gate should keep `validated`, `synthetic_fixture`, `original_link`, and `candidate` distinct. A larger candidate list must not be used as an adoption or scientific-quality claim.
