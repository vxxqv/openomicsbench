# Candidate sources for the combined v15 release

**Status, 27 November 2026:** source discovery only. These are not added to the scored collection until the indicated files, rights, transformations, assembly/annotation compatibility and expected outputs have been checked. Do not add them to the validated-object count or claim them as new package datasets yet.

| Audience | Source and candidate cases | Why it is relevant | Required work before scoring |
| --- | --- | --- | --- |
| Single-cell | [CellBench / sc_mixology](https://github.com/LuyiTian/sc_mixology): `sc_10x`, `sc_celseq2`, `sc_dropseq`, `sc_10x_5cl` count/metadata CSVs. Source experiment [GSE118767](https://www.ncbi.nlm.nih.gov/geo/query/acc.cgi?acc=GSE118767). | Three platforms and a five-line mixture; `cell_line_demuxlet` is an experimental reference label. | Pin upstream commit and hashes; check whether the repository MIT license covers derived count/metadata subsets; audit label completeness, barcode alignment, rare classes, and protocol confounding. All four are one study, so an independent second source is required. |
| Single-cell second origin | [10x Genomics 5k Human PBMC Donor 2](https://www.10xgenomics.com/datasets/5k_Human_Donor2_PBMC_3p_gem-x), CC BY 4.0. | Independent public single-cell data and an actual second source. | Obtain and hash processed matrix; source only has platform output, so any cell-type annotation must be labeled a reference annotation rather than ground truth. Add a cited annotation source or use as a non-scored format/QC case. |
| Small variants | [NIST Genome in a Bottle](https://www.nist.gov/programs-projects/genome-bottle): version-matched truth VCF/BED pairs for HG001–HG004, GRCh38. | Independent reference samples and official benchmark regions. | Pin exact benchmark release, VCF, BED and reference FASTA; verify checksums; get query call sets; run [hap.py](https://github.com/Illumina/hap.py) for representation-aware comparison. The package's exact-match command is an audit baseline only. |
| Chromatin | [ENCODE ATAC-seq standards and file portal](https://www.encodeproject.org/data-standards/atac-seq/atac-encode4/). | Replicated peaks, QC, and external IDR outputs support the new reporting command. | Select four specific experiment/file accessions, verify genome assembly, blacklist, replicate pairing and file versions, and obtain matched external FRiP/TSS/IDR measurements. Do not treat overlap as biological truth. |
| Processed proteomics | [PRIDE/pmultiqc example datasets](https://www.ebi.ac.uk/pride/services/pmultiqc/): PXD003133, PXD061709, PXD039477 and PXD062399. | MaxQuant, DIA-NN, MaxDIA and FragPipe processed outputs broaden format coverage. | Confirm exact processed-file links, accession mapping and reuse terms; pick a declared reference or make these parser/format cases only. An identification table from one pipeline is not independent truth for another. |

The release gate should keep `validated`, `synthetic_fixture`, `original_link`, and `candidate` distinct. A larger candidate list must not be used as an adoption or scientific-quality claim.
